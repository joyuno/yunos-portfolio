2026.04 ~ 현재 MVP 완성 · 2금융권 도입 검토 중 풀스택 메인 개발자 중앙회/조합회/은행 분리

Project Overview

tr-box는 멀티테넌트를 지원하는 SIEM 연동 소명처리 시스템입니다. SIEM이 생성한 보안 알람을 양방향으로 동기화하여 케이스로 가져오고, 자동 소명 메일 발송 → 다단계 결재 → 자체 호스팅 LLM 자동 소견 생성 → matplotlib PDF 보고서 → 100% 감사 추적까지 단일 플랫폼에서 처리합니다. 2금융권의 중앙회 / 조합회 / 은행 조직 구조에 맞춘 멀티테넌트 아키텍처로 한 인스턴스가 다수 조직을 수용합니다.

My Contributions

  • 소명 워크플로우 (단독) — 자동 분류, 메일 발송, 다단계 결재, 위임, 만료 알림.
  • 멀티테넌트 아키텍처 (단독) — 중앙회 / 조합회 / 은행 트리 구조, site_guid 라우팅, 임직원 CSV 업로드 + 테넌트 자동 라우팅.
  • SIEM 양방향 연동 (단독) — 알람 수집 + 결재 결과 푸시 + 티켓 메모 동기화.
  • SSO 인증 + 직급-역할 매핑 자동 계정 등록.
  • 자체 호스팅 LLM 자동 소견 — 소명 보고서 종합 소견 자동 생성.
  • matplotlib PDF 보고서 — 차트 곡선화, 페이지 오버플로우 방지.
  • React 어드민 UI — 카드 드래그 방식 예외 정책, 다크모드, 권한별 대시보드.
  • 인프라 — Self-hosted Runner CD + Docker Compose HA + Nginx HTTPS.

Key Technical Decisions

  • users ⊥ tenants 직교 멀티테넌트 모델 — 헤더 기반 런타임 권한 전환으로 JWT 재발급 없이 tenant 전환.
  • 케이스 상태 FSM 강제 경유 — 직접 status 변경 차단으로 비정상 전이 방지.
  • SIEM 커넥터 추상화 (BaseConnector) — 신규 SIEM은 상속만으로 통합 가능.
  • LLM On-Premise 자체 호스팅 — 보안 운영 데이터 외부 송출 차단.
  • Self-hosted Runner — 폐쇄망 / 내부 IP 환경 대응.
