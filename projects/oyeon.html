오연(五緣) — 사주 기반 1일 1매칭 소개팅 앱

매일 오후 5~6시, 사주 궁합이 가장 좋은 단 한 명을 추천. 겉/속/성격 3축 + LLM 자연어 해설. Flutter 단일 코드베이스로 iOS·Android·Web을 동시에 지원하며, 먹·한지·인장 모티프로 사주의 문화적 무게를 UI로 전달합니다.

2025 - 현재 Flutter Multi-platform 사주 도메인 풀 구현 LLM 자연어 해설

Overview

무한 스와이프 매칭의 피로감을 거부한 1일 1매칭 모델로 설계한 사주 기반 소개팅 앱입니다. 천간 / 지지 / 지장간 / 60갑자 / 오행 상생상극 / 대운까지 사주 도메인을 백엔드에 풀 구현하고, Anthropic Claude API로 "왜 잘 맞는가"를 자연어로 설명합니다. 만 19세 인증 · 계정 삭제 · 신고/차단 · 프로필 사진 수동 심사 등 앱스토어 정책을 사전 준수했습니다.

Key Features

  • 1일 1매칭 모델 — 매일 17~18시 알고리즘 기반 단 한 명 자동 추천. 무한 스와이프 거부.
  • 다축 궁합 분석 — 겉궁합 / 속궁합(육체적·정신적) / 성격궁합 0~100점 + 주(柱)별 상세.
  • 사주 도메인 풀 구현 — 천간 10 / 지지 12 / 지장간 / 60갑자 / 오행 상생상극 / 대운(10년 단위) / 입춘 보정.
  • LLM 자연어 해설 — Anthropic Claude API로 단순 점수가 아닌 "왜 잘 맞는가"를 사람의 언어로 설명.
  • 실시간 1:1 채팅 — 상호 좋아요 후 WebSocket 기반 활성화.
  • 지역 기반 매칭 — 서울 25구 + 경기/인천 인접 구 단위.
  • 개인정보 안전 설계 — 연락처 차단을 SHA256 해시로 처리해 원본 비저장.
