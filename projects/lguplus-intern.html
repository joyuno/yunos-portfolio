LG U+ MVNO 업무 자동화

LG U+ MVNO 영업1팀 단순 반복 업무 자동화 프로젝트. 매일 손으로 하던 경쟁사 요금제 조사를 수집, 엑셀 리포트, 메일 발송까지 자동화해 하루 2시간 걸리던 일을 15분으로 줄였습니다.

2025 LG U+ Internship Business Automation

Overview

LG U+ MVNO 영업1팀에서 사무 인턴으로 근무하며 경쟁사 요금제 변동 이슈 분석, 뉴스 감성 분석, 커뮤니티 여론 분석 업무를 자동화했습니다. 팀원이 모두 비개발 직무였고 요금제 조사는 사무보조 업무라 자동화를 고민하는 사람이 없었습니다. 처음 업무를 맡을 때부터 자동화할 수 있다고 보고 남는 시간에 틈틈이 만들어 하루 2시간 걸리던 일을 15분으로 줄였습니다. 사무보조 인원이 줄면 이 일이 선임들 몫이 될 것 같아 선임들에게 넘기자고 제안했고 비개발자도 계속 쓸 수 있게 사용 가이드를 만들어 전달했습니다.

Business Impact

매일 아침 손으로 하던 경쟁사 요금제 조사를 수집, Pandas 엑셀 리포트, 메일 발송까지 자동화했습니다. 하루 2시간 걸리던 일이 15분으로 줄었습니다.

Key Deliverables

1

MVNO Promotion Crawler

7개 경쟁사 사이트(모요플랜, 아이즈, 프리티, 모빙, 스마텔, 이야기, 티플러스)에서 요금제 정보를 자동 수집하고 비교 분석 리포트 생성.

2

매일 리포트 자동 발송

크롤링 결과를 Excel로 정리해 담당자에게 메일로 보냅니다. 인턴 종료 후에는 개인 저장소로 옮겨 GitHub Actions로 매일 오전 7:30에 돌도록 정리했습니다.

3

News Sentiment Analysis

Naver API로 알뜰폰 관련 뉴스 수집, TF-IDF 중복 필터링, HuggingFace 감성 분석 모델로 긍정 뉴스 자동 추출.

4

Community Sentiment Monitoring

뽐뿌 커뮤니티에서 MVNO 관련 게시글 수집, KOTE 감성 분석 모델로 44개 감정 라벨 분류 및 여론 분석.

MVNO Promotion Crawler

다양한 MVNO 비교 사이트에서 요금제 정보를 수집하는 Selenium 기반 웹 크롤러입니다. 각 사이트의 구조에 맞춘 커스텀 파서를 구현하고 데이터를 정규화하여 비교 가능한 형태로 가공합니다.

Results & Impact

  • 업무 자동화: 하루 2시간 걸리던 수동 조사를 15분으로 단축
  • 데이터 정확성: 수동 입력 오류 제거, 일관된 데이터 포맷 유지
  • 실시간 모니터링: 경쟁사 가격 변동 및 프로모션 즉시 감지
  • 의사결정 지원: 데이터 기반 요금제 전략 수립에 기여
  • 확장성: 새로운 사이트 추가 시 모듈식 파서 구조로 빠른 대응 가능

Key Learnings

실제 비즈니스 환경에서 쌓은 데이터 엔지니어링 경험. 웹사이트 구조 변경에 대응하는 유지보수, 안정적인 스케줄링, 비개발자 동료에게 결과물 전달 등 실무 역량 향상.
