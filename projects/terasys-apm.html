terasys-apm — On-Premise APM Platform

테라시스 자체 APM 솔루션. OpenTelemetry + ClickHouse 위에 ML 2-Layer 이상 탐지와 자사 LLM 파인튜닝 모델을 통합한 2금융권용 자체 제품.

2026.02 ~ 현재 MVP · 2금융권 도입 검토 중 풀스택 + ML/LLM 담당 3인 팀

Project Overview

자사 자체 APM 제품 신규 사업 라인. OpenTelemetry 위에서 On-Premise APM을 자체 구축하고, ML 이상 탐지와 자사 LLM 기반 자연어 쿼리 기능을 통합합니다. 2금융권 도입 검토 단계의 MVP입니다.

My Contributions

  • ML 2-Layer 이상 탐지 엔진 (단독) — z-score 임계값 + 분산 보정 + 이상 발생 밀도 heatmap.
  • 자사 LLM 파인튜닝 통합 — 사내 DGX 서버에서 Qwen2.5-14B 파인튜닝 모델 추론 통합.
  • 자사 LLM Text-to-SQL 기능 — 자연어 쿼리를 ClickHouse SQL로 변환하는 보유 기능.
  • React 어드민 UI 메인 개발 — MVVM 리팩토링, 커스텀 위젯 빌더, 쿼리 탐색기, X-view 시점 분석, SSE 실시간 대시보드, 2K UI 최적화.
  • Go 백엔드 — 핸들러 / 스토어 / 쿼리 / 알림 / SSO 인증, Clean Architecture 적용.
  • Self-hosted runner CI/CD — 폐쇄망 배포 환경 대응, SSH 의존 제거, Nginx HTTPS, ClickHouse 처리량 약 4배 향상 (background_pool_size 4→16).
  • OTel 자바 자동계측 데모 — 결제 / 주문 마이크로서비스 시연 환경.

Key Technical Decisions

  • OpenTelemetry — 벤더 종속 회피, 자동 계측 풍부, 사실상 산업 표준.
  • ClickHouse — traces/metrics/logs 단일 OLAP, 컬럼 압축, 고속 집계.
  • 사내 DGX + Qwen2.5-14B 파인튜닝 — On-Premise 환경 요구, 외부 API 의존 최소화.
  • MVVM + Clean Architecture — 컴포넌트 / 뷰모델 / 서비스 분리로 테스트 용이.
  • Self-hosted runner — 폐쇄망 배포 환경 대응.
